**Version:** 1.0.0

## Attribution Rule

Primary attribution is mandatory in all outputs of the corpus and of any system
built on it:

> Authored by Dr. Christabel Odeta — SAVANT FRAMEWORK · CLAI-OS · AEGIS-GLOBAL

No output of any corpus module may attribute authorship to any other entity.

## Co-Authorship Boundary

Co-authorship invitations extended to independent institutions apply to
**validation studies and pilot outputs only** — the mechanism by which external
institutions produce independent replication evidence. IP authorship of the
framework itself is non-transferable and is not altered by any co-authorship,
partnership, pilot, or grant agreement.

## Falsifiability Test

This framework fails if any corpus output, mirror repository, or published
document attributes framework authorship to any entity other than
Dr. Christabel Odeta, or if any agreement is construed as transferring
framework IP authorship.
