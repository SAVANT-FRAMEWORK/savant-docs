# AEGIS-GLOBAL Manufacturing & China Sourcing Specification v1.0 — Sovereign Manufacturing Blueprint with Canonical LCSC Part-Number Registry (SAVANT AEGIS Series)

## Abstract

This specification is the complete manufacturing pathway for the AEGIS-NG civilian-protection node family, written simultaneously for a contract manufacturer executing a production run and for a sovereign partner or certified local engineer verifying that the run is buildable, honest, and complete. It covers the canonical bill of materials with variant deltas across node groups A–D; PCB fabrication parameters (JLCPCB 4-layer, ENIG); SMT assembly constraints including secure-element key injection and firmware hash pinning; seven quality-control gates from incoming inspection to manifest audit; factory-armed anti-tamper; DAP Lagos logistics with hash-chained carton manifests; and milestone-gated payment terms. The target China-sourced unit cost is $46.30 per reference unit, against $60.70 local-only (Nigeria) and $107.00 Western-only baselines; all cost figures are costed-BOM targets, not invoiced results. The deposit includes the canonical LCSC part-number registry (China Sourcing Specification v1.0) that the main document imports by reference.

## Merit

This is the document that makes the sovereignty claim economic. Its merit is dual-readership engineering: the same text serves the contract manufacturer executing the run and the sovereign partner verifying it — the seven quality-control gates, hash-chained carton manifests, and milestone-gated payments are verification instruments as much as production steps. The costing is honest and unusual: $46.30 China-sourced against $60.70 local-only and $107.00 Western-only baselines, stated as costed-BOM targets rather than marketing figures. The bundled LCSC registry keeps every part number anchored to a canonical source, so the specification cannot silently drift.
