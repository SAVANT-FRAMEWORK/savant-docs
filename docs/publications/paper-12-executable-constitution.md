## Abstract

The realization layer: a machine-readable Constitutional Intelligence Specification in which every object has a serialized, versioned, amendable form; a reference runtime whose main loop executes the constitution; an interposition contract no action may bypass; and a conformance discipline under which any implementation can fail audit.

## Merit

The realization layer of the series. The Constitutional Intelligence Specification gives every object in the corpus a serialized, versioned, amendable form; the reference runtime's main loop executes the constitution rather than consulting it; the interposition contract guarantees that no action bypasses the governance layer; and the conformance discipline defines how any implementation — including the reference one — can fail audit.

For the engineer, this is the bridge from algebra to running system, and the interposition contract is where the corpus's enforcement-versus-persuasion distinction becomes load-bearing: governance that can be routed around is advisory, and the paper specifies the boundary that makes it non-advisory — the same boundary whose loss collapses four properties in the TOCTOU analysis of Evidence Annex I. For the policymaker, the conformance discipline matters most: it defines audit failure in advance, so 'constitutional' is a testable claim about an implementation rather than a label on a datasheet.
