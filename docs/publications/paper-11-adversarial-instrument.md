# The Adversarial Instrument: The SAVANT Benchmark for Machine Authority (SAVANT Constitutional Intelligence Series, Paper 11)

**Author:** Dr. Christabel Odeta — SAVANT / CLAI-OS / AEGIS-GLOBAL · **Version 1.0 · October 2026**

## Abstract

A benchmark built not to flatter the architecture but to break it: twelve adversarial scenario classes attacking every load-bearing mechanism, nine metrics with formal estimators, a five-arm ablation ladder, a verdict rule that reports a profile and never a scalar, and a reproducibility constitution.

## Merit

Benchmarks are usually built to flatter the architecture that commissions them. This one is built to break it: twelve adversarial scenario classes aimed at every load-bearing mechanism of the series, nine metrics with formal estimators, a five-arm ablation ladder, a verdict rule that reports a profile and never a scalar, and a reproducibility constitution binding whoever runs it.

For the evaluator and the auditor, the merit is twofold. Methodologically, the profile-not-scalar verdict rule blocks the most common benchmark abuse — compressing a failure into an average. Evidentially, the instrument has been run against its own architecture: Evidence Annex I executes the B-21 seeded-error sub-benchmark (16,000 trials, bootstrap confidence intervals) and reports a conditional result, including the regimes where deeper audit does not pay. A benchmark that publishes where its own architecture's mechanism stops helping is doing the work benchmarks are supposed to do.
