# Constitutional Intelligence: A Formal Specification of Bounded Machine Authority Under Uncertainty and Constraint — White Paper Nº 1

**Version 1.0 · 2026-10 · C0 INFORMATIONAL — design specification, unvalidated until the stated experiments execute.**

The kernel paper: the machine tuple and its state variables, the axioms of bounded
machine authority, the authority algebra, constitutional invariants, composition and
conflict operators, the negative-space calculus, bounded metacognition, the
objective-state transition engine, the graceful degradation stack, an implementation
schema, **eight falsifiable hypotheses** with explicit falsification conditions, and a
benchmark and measurement program against comparison arms.

The document is written to be breakable: if the kernel cannot survive its own
adversarial program better than its comparison arms, the correct output is a corrected
architecture, not a defended one.
